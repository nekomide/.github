**Nekomide** is an IDE for web development. It features a wide variety of customization options and quality-of-life features that help developers do what they do best.

Nekomide is currently in development, and the desktop application repository is private. To get updates on development, you can join the [Discord server](https://discord.rayne.page).

## Team
Nekomide is developed, directed, and maintained by [Rayne D](https://github.com/raynecloudy). To view the entire Nekomide Team, visit [TEAM.md](../TEAM.md).

### Open positions
If you can write a language other than English, consider [contacting a maintainer](https://rayne.page/contact) to become a translator for Nekomide.
